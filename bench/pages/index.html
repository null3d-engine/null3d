Benchmark pages

Each page runs one benchmark scene. A run warms up, then measures every frame, and shows its report on the page when it ends. The scenes and the run times come from bench/scenes/spec.ts.

Switches

  • ?renderer=webgl or ?renderer=webgpu: the three.js renderer. One is required. The WebGPU renderer never falls back to WebGL.
  • ?hold: render one frame at the hold time into an offscreen target, and publish its pixels for parity images.
  • ?n=1000: the instance count of S1, S1-static and S1-cells, the box count of S3, or the character count of S5, instead of the full count. S2 rounds it up to whole trees, and S4 ignores it.
  • ?preset=low: the quality preset of S4, S5 and their twins, instead of the one that null3D chooses for the device.
  • ?demo: run the scene until the page closes, with no measurement. S5's null3D page is then a playable demo with the stats overlay.
  • ?seconds=2: warm up and measure for this many seconds each, for quick checks.

three.js twins

  • S1, the swarm (moving instances, orbiting camera): WebGL, WebGPU; hold frame on WebGL, WebGPU; quick run on WebGL, WebGPU
  • S1-static (still instances, fly-through camera): WebGL, WebGPU; hold frame on WebGL, WebGPU; quick run on WebGL, WebGPU
  • S1-cells (still instances over 8 x 8 grid cells, low flight): WebGL, WebGPU; hold frame on WebGL, WebGPU; quick run on WebGL, WebGPU
  • S2, the hierarchy (trees of separate objects whose roots turn, orbiting camera): WebGL, WebGPU; hold frame on WebGL, WebGPU; quick run on WebGL, WebGPU
  • S3, the lights (still boxes on a floor, 256 moving point lights, orbiting camera): WebGL, WebGPU; hold frame on WebGL, WebGPU; quick run on WebGL, WebGPU
  • S4, the phone scene (a town with vehicles, shadows, street lights and fog; circling camera): WebGL, WebGPU; hold frame on WebGL, WebGPU; quick run on WebGL, WebGPU
  • S5, the crowd (animated characters from a glTF file walk in rings, with shadows; orbiting camera): WebGL, WebGPU; hold frame on WebGL, WebGPU; quick run on WebGL, WebGPU

Playable demos

  • S5, the crowd, in null3D with the stats overlay: drag to turn the camera, scroll or pinch to zoom, and press Space to pause the crowd. WebGPU or WebGL2, WebGL2; its three.js twin on WebGL, WebGPU

Feature scenes

Each page draws one feature's scene once with three.js and publishes its pixels. The parity test compares them with null3D's image test of the same scene.

  • The orthographic camera: WebGL, WebGPU
  • The standard material's grid over metalness and roughness: WebGL, WebGPU
  • The standard material's grid in an environment, the room of RoomEnvironment: WebGL, WebGPU; an HDR sunset: WebGL, WebGPU; the sunset turned: WebGL, WebGPU
  • 16 point lights: WebGL, WebGPU; spot lights: WebGL, WebGPU; a hemisphere light: WebGL, WebGPU
  • ACES tone mapping without anti-aliasing, on WebGL only: WebGL
  • The standard material's texture maps: WebGL, WebGPU
  • Linear fog: WebGL, WebGPU; exponential squared fog: WebGL, WebGPU
  • The directional light's shadows: WebGL, WebGPU
