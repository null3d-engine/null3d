Third-party code in the null3D Vite plugin

The @null3d/vite-plugin package ships a WebAssembly module, dist/shader-compiler.wasm, which the
build runs to compile the engine's WGSL. The module is built from the null3D crates and the Rust
crates below. Each section names the crates, their licenses, and the notices that a license asks a
copy to carry. The npm packages that the plugin depends on carry their own licenses.
