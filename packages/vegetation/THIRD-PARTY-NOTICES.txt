Third-party code in @null3d/vegetation

The @null3d/vegetation package ships code from the project below. The section names the file
that holds the code, its licence, and the notices that the licence asks a copy to carry.

A build with the null3D Vite plugin writes this text into null3d-third-party-notices.txt beside
the page, after the engine's own notices. Keep that file with the build when you publish it, or
show its text in your game's credits.

==============================================================================
three.js: the plant shader's tangent frame (render/plant.wgsl, in index.js)
==============================================================================

A port of three.js 0.186.1, https://github.com/mrdoob/three.js: getTangentFrame in
src/renderers/shaders/ShaderChunk/normalmap_pars_fragment.glsl.js, which builds a surface's tangent
frame from the screen derivatives of its position and its texture coordinates.
