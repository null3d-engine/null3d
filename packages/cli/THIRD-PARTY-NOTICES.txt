Third-party code in the null3D command-line tool

The @null3d/cli package ships code from the projects below, built to WebAssembly, in its vendor
folder. Each section names the files that hold the code, its licence, and the notices that the
licence asks a copy to carry. The npm packages that the tool depends on carry their own licences.
