# null3d

This package gives the [null3d](https://github.com/null3d-engine/null3d) command-line tool its plain name, so `npx null3d` works anywhere, even outside a project. It runs [`@null3d/cli`](https://www.npmjs.com/package/@null3d/cli).

In a project, install `@null3d/cli` instead. You do not need either package to use the engine: install `@null3d/engine`, add `@null3d/vite-plugin` to your Vite config, and run Vite.
