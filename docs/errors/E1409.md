# E1409: Invalid memory maximum

## What happened

The memory option of createEngine asked for a maximum that is not a whole number of MiB from 256 to 4096.

## How to fix it

Give memory.maximumMiB a whole number of MiB from 256 to 4096, such as 2048, or leave the option out for the default of 1024.

[Where problems appear](../guides/debugging.md#where-problems-appear) says where each kind of error reaches your code.

## Example message

The engine prints the part below, then the fix above and a link to this page.

```text
E1409: the memory.maximumMiB option 8192 is not a whole number of MiB from 256 to 4096.
```
