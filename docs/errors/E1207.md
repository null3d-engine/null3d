# E1207: Invalid layer mask

## What happened

A call that sets layers received a number that is not a 32-bit layer mask: a fraction, NaN, or a number past 32 bits.

## How to fix it

Pass a whole number whose bits name the layers: 1 << n is layer n. The operator | joins layers, so (1 << 0) | (1 << 3) is layers 0 and 3. Layers run from 0 to 31.

## Example

```text
E1207: setLayers() got 2.5 on "Player" (slot 12), which is not a 32-bit layer mask.
```
