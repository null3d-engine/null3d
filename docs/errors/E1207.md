# E1207: Invalid setting

## What happened

A call received a setting that it does not have, or a value that the setting does not take. Examples are a tone mapping that the engine does not know, and a negative exposure.

## How to fix it

Pass only the settings that the call has, each with a value that it takes. The call's docs page lists them.

## Example

```text
E1207: post.set() got the tone mapping "filmic", which is not 'aces', 'agx', 'neutral' or 'none'.
```
