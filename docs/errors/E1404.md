# E1404: Engine thread failed

## What happened

An engine thread hit an error it could not handle after the engine started, so the engine may have stopped.

## How to fix it

This is an engine bug. Report it with the message and the browser, then destroy the engine and start it again.

## Example

```text
E1404: the render worker failed: out of memory.
```
