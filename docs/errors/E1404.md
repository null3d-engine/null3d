# E1404: Engine thread failed

## What happened

An engine thread, or the drawing on the page, hit an error it could not handle. After the start the engine may have stopped. During the start, createEngine() stops the engine and rejects with this error.

## How to fix it

This is an engine bug. Report it with the message and the browser, then destroy the engine and start it again.

## Example

```text
E1404: the render worker failed: out of memory.
```
