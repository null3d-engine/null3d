# E1501: Render space full

## What happened

The scene needs more room than the renderer set aside. The full part is the draw list, the mesh buffers, the material table, the upload space or the culling pass.

## How to fix it

Share meshes and materials between objects instead of creating them per object. Draw many copies of one mesh with an instance batch.

## Example

```text
E1501: materials.standard() failed: the material table is full.
```
