# E1408: Hold failed

## What happened

The sketch or the engine failed in hold mode, before the engine read the held frame back. A live engine logs an error in the sketch and carries on. Hold mode stops at the first one, so a test fails at once.

## How to fix it

Fix the error that the message quotes. When the message gives a sketch time, the sketch failed at that time, and the console shows the error with its stack.

[Where problems appear](../guides/debugging.md#where-problems-appear) says where each kind of error reaches your code.

## Example message

The engine prints the part below, then the fix above and a link to this page.

```text
E1408: hold mode stopped at 0.75 seconds, in frame 46: TypeError: player is undefined.
```
