# E1106: Object never created

## What happened

A call such as `setVisible` or `setParent` queued a change for an object that the engine never created. The engine creates an object when the next frame starts. When that fails, for example because its parent was destroyed, the object never joins the scene.

## How to fix it

Fix the call that created the object. When the frame applied that call, the engine logged why it failed, such as E1101 for a parent that was already destroyed.

## Example

```text
E1106: a queued change named an object (slot 7), which the engine never created.
```
