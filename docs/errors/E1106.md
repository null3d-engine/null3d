# E1106: Object not created yet

## What happened

A call read world data of an object in the frame that created it. New objects join the scene when the next frame starts.

## How to fix it

Read world positions and matrices from the next frame on, for example in the next onUpdate call.

## Example

```text
E1106: getWorldPosition() on "Crate" (slot 7) ran before the frame that creates it.
```
