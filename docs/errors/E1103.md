# E1103: Object from another engine

## What happened

A call received an object that this engine did not create.

## How to fix it

Pass objects created by this engine. Each engine has its own scene, and objects do not move between engines.

## Example

```text
E1103: createInstances() got a mesh that is not from this engine.
```
