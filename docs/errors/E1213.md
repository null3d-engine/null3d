# E1213: Invalid setting

## What happened

A call received a setting that it does not have, or a value that the setting does not take. A tone mapping that the engine does not know, or a grading control outside its range, are examples.

<details>
<summary>Technical details: the calls and settings that raise it</summary>

`post.set()` refuses a tone mapping that the engine does not know, a negative exposure, and a grading control outside its range.

`assets.builtinEnvironment()` refuses a name that no built-in environment has.

`assets.registerGltfExtension()` refuses a handler that names no extension, that another handler reads, or that returns a part without a mesh or a material.

`createEngine()` refuses sketch data that is not plain JSON data, or that takes more than 64 KiB as JSON.

</details>

## How to fix it

Pass only the settings that the call has, each with a value that it takes. The call's docs page lists them.

[Where problems appear](../guides/debugging.md#where-problems-appear) says where each kind of error reaches your code.

## Example message

The engine prints the part below, then the fix above and a link to this page.

```text
E1213: post.set() got the tone mapping "filmic", which is not 'agx', 'agx-punchy', 'neutral', 'aces' or 'none'.
```
