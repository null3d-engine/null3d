# E1203: Invalid number

## What happened

A call received a number that is not finite, such as NaN or Infinity.

## How to fix it

Check the value computed before this call: NaN often comes from dividing zero by zero, or from normalizing a zero-length vector. Most calls check their numbers only in development builds, and a release build leaves the check out. The bad value then reaches the scene, and the frame draws wrong, or not at all, with no error. Scene queries such as raycasts check in every build.

[Where problems appear](../guides/debugging.md#where-problems-appear) says where each kind of error reaches your code.

## Example message

The engine prints the part below, then the fix above and a link to this page.

```text
E1203: setPosition() got NaN for x on "Player" (slot 12). Check the value computed before this call.
```
