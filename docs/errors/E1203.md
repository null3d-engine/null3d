# E1203: Invalid number

This page is generated from the engine's error table, `packages/engine/src/errors/codes.ts`. To change it, edit the table.

## What happened

A call received a number that is not finite, such as NaN or Infinity.

## How to fix it

Check the value computed before this call. NaN often comes from dividing zero by zero, or from normalizing a zero-length vector.

E1203: setPosition() got NaN for x on "Player" (slot 12). Check the value computed before this call.
