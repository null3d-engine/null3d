# E1414: Frame not captured

## What happened

engine.capture() could not give an image of a frame. The engine had stopped, or the thread that draws could not read the frame back from the GPU or encode it.

## How to fix it

Call engine.capture() while the engine runs, before destroy(). When the message names a GPU failure, wait for the engine to recover from it and call capture() again.

## Example

```text
E1414: engine.capture() failed: the engine has stopped.
```
