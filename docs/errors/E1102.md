# E1102: Too many objects

## What happened

The scene, the table of instance batches or the queue of changes for the next frame is full. The message names which one, and how many it holds.

## How to fix it

Draw many copies of one mesh with scene.createInstances(): a batch takes none of the places for objects, however many rows it has. Destroy the objects and batches that you no longer need, and spread a very large number of changes over several frames.

## Example

```text
E1102: createMesh() failed: the scene already holds 32767 objects.
```
