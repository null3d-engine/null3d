# E1303: WebAssembly SIMD missing

## What happened

The browser runs WebAssembly without SIMD, which the engine's core needs.

## How to fix it

Update the browser. Chrome and Edge 91, Firefox 89, Safari 18 and later versions run the engine.

[Where problems appear](../guides/debugging.md#where-problems-appear) says where each kind of error reaches your code.

## Example message

The engine prints the part below, then the fix above and a link to this page.

```text
E1303: this browser runs WebAssembly without SIMD.
```
