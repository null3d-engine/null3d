# E1303: WebAssembly SIMD missing

## What happened

The browser runs WebAssembly without SIMD, which the engine's core needs.

## How to fix it

Update the browser. Chrome 91, Firefox 89, Safari 16.4 and later versions run the engine.

## Example

```text
E1303: this browser runs WebAssembly without SIMD.
```
