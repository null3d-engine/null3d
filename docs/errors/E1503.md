# E1503: Target created twice

## What happened

Two render passes create the same target, or a pass creates a target that the render graph keeps between frames. A sketch's pass whose texture has the name of a target of the engine's own passes does this. Each target has one creator, which sets its format and size.

## How to fix it

Give each pass's texture a name that no other pass writes. The engine's own passes write sceneColor, sceneDepth, outlineMask and the other names that render.dumpGraph() shows, so pick another name.

## Example

```text
E1503: both "Opaque" and "Sky" create "sceneColor".
```
