# E1504: Render pass cycle

## What happened

Render passes need each other in a loop, so no order runs each pass after the passes whose output it reads. A sketch's pass that reads its own texture makes such a loop.

## How to fix it

Break the loop: a pass cannot read its own texture. To show a mirror in a mirror, add a pass for the inner mirror first, and let the outer pass read its texture.

## Example

```text
E1504: the passes form a cycle: "Tint" runs after "Glow", and "Glow" after "Tint".
```
