# E1504: Render pass cycle

## What happened

Render passes need each other in a loop, so no order runs each pass after the passes whose output it reads. A sketch's pass that reads its own texture, or two passes that read each other's, make such a loop.

## How to fix it

Break the loop: a pass cannot read its own texture, or the texture of a pass that reads its own. To show a mirror in a mirror, give the second mirror a pass of its own that reads neither.

## Example

```text
E1504: the passes form a cycle: "Tint" runs after "Glow", and "Glow" after "Tint".
```
