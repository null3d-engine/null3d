# E1504: Render pass cycle

## What happened

Render passes need each other in a loop, so no order runs each pass after the passes whose output it reads.

## How to fix it

The engine declares every render pass itself, so this is an engine bug. Report it with the message, the browser and the quality preset.

## Example

```text
E1504: the passes form a cycle: "Tint" runs after "Glow", and "Glow" after "Tint".
```
