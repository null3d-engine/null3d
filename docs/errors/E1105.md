# E1105: Unknown command

## What happened

The engine core received a structural change it does not know, so the engine's JavaScript and its core come from different builds.

## How to fix it

Reinstall the engine package so all of its parts come from one version. If you build the engine from source, run bun run build again.

[Where problems appear](../guides/debugging.md#where-problems-appear) says where each kind of error reaches your code.

## Example message

The engine prints the part below, then the fix above and a link to this page.

```text
E1105: the engine core received command 42.
```
