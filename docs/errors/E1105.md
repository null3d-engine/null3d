# E1105: Unknown command

## What happened

The engine core received a structural change it does not know, so the TypeScript side and the core come from different builds.

## How to fix it

Reinstall the engine package so all of its parts come from one version. If you build the engine from source, run bun run build again.

## Example

```text
E1105: the engine core received command 42.
```
