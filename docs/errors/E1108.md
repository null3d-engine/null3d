# E1108: Value out of range

## What happened

A call received a number outside the range it takes. Examples are a row past the capacity of an instance batch, an opacity above 1, a negative radius, and a camera's far plane that does not lie beyond its near plane.

## How to fix it

Pass a value inside the range that the message gives. For an instance batch, keep counts and indices within the capacity you created it with, or create a larger batch.

## Example

```text
E1108: setActiveCount() got 1200, above the limit of 1000.
```
