# E1108: Value out of range

## What happened

A call received a value outside the range it takes. Counts and indices have limits, such as the capacity of an instance batch. Settings have ranges too: an opacity goes from 0 to 1, and a camera's far plane must lie beyond its near plane.

## How to fix it

Keep counts and indices within the capacity you created the batch with, or create a larger batch. Keep a setting within the range that the message and the call's docs page give.

## Example

```text
E1108: setActiveCount() got 1200, above the limit of 1000.
```
