# E1104: Parent loop

## What happened

A call would make an object its own ancestor: the new parent is the object itself or one of its descendants.

## How to fix it

Choose a parent outside the subtree of the object. To swap two objects in a hierarchy, move one of them to the root first.

[Where problems appear](../guides/debugging.md#where-problems-appear) says where each kind of error reaches your code.

## Example message

The engine prints the part below, then the fix above and a link to this page.

```text
E1104: a queued change on an object (slot 9) would put it under its own descendant (slot 12).
```
