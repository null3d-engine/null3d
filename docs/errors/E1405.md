# E1405: Engine thread did not start

## What happened

An engine thread failed while the engine started, before the sketch ran.

## How to fix it

Read the message for the thread and its cause. Check that the page is served with the isolation headers and that the engine files load, then report it if it repeats.

## Example

```text
E1405: the render worker did not start: no WebGPU adapter.
```
