# E1406: Engine core not downloaded

## What happened

A file of the engine core did not download whole: the server answered with an error, or the connection broke off.

## How to fix it

Check that the host serves the files from the engine's dist/wasm folder at the paths that the build gave them. If the page loads at other times, the network dropped: reload the page.

## Example

```text
E1406: /assets/null3d_memory-3f9c1a2b.json did not download: HTTP 404.
```
