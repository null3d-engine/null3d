# E1204: Invalid color

## What happened

A call received a color that is not a hex string, a number from 0 to 0xffffff, or three numbers from 0 to 1.

## How to fix it

Pass a hex string such as '#4a8cff', a number such as 0x4a8cff, or three linear components from 0 to 1, such as [0.07, 0.26, 1].

[Where problems appear](../guides/debugging.md#where-problems-appear) says where each kind of error reaches your code.

## Example message

The engine prints the part below, then the fix above and a link to this page.

```text
E1204: setBackground() got the color "blue-ish".
```
