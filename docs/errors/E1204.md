# E1204: Invalid color

This page is generated from the engine's error table, `packages/engine/src/errors/codes.ts`. To change it, edit the table.

## What happened

A call received a color that is not a hex string, a number from 0 to 0xffffff, or three numbers from 0 to 1.

## How to fix it

Pass a hex string such as '#4a8cff', a number such as 0x4a8cff, or three sRGB components from 0 to 1, such as [0.29, 0.55, 1].

## Example

```text
E1204: createLambertMaterial() got the color 'blue-ish'.
```
