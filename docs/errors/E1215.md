# E1215: Invalid custom WGSL

## What happened

`materials.shader()`, `post.addEffect()`, `post.set()` or `scene.setSkyLayer()` received WGSL that it cannot draw with. The engine takes only WGSL that the null3D Vite plugin compiled, as a shader of the kind that the call takes.

## How to fix it

Add the null3D Vite plugin to `vite.config.ts`. Write the WGSL in a template literal right after a `/* wgsl */` comment, or import it from a `.wgsl` file. Give each call the WGSL that its kind declares: the table on this page lists each declaration.

<details>
<summary>Technical details: the WGSL that each call declares</summary>

| Call | WGSL declares |
| --- | --- |
| `materials.shader()`, surface | `fn surface(input: SurfaceInput) -> Surface`, with no `@vertex` or `@fragment` entry |
| `materials.shader()`, vertex offset | `fn vertexOffset(input: VertexInput) -> vec3f` |
| `materials.shader()`, lobe | `fn lobe(input: LobeInput) -> vec3f` |
| `materials.shader()`, full shader | a `@vertex` entry that takes an `InstanceIn` from `null3d::mesh` |
| `materials.shader()`, own vertices | a `@vertex` entry with `@builtin(vertex_index)` and `@builtin(instance_index)`, and no mesh attribute |
| `post.addEffect()` | `fn effect(input: EffectInput) -> vec4f` |
| `post.set({ toneMapping })` | `fn toneCurve(color: vec3f) -> vec3f` |
| `scene.setSkyLayer()` | `fn skyLayer(input: SkyLayerInput) -> SkyLayer` |

</details>

[Where problems appear](../guides/debugging.md#where-problems-appear) says where each kind of error reaches your code.

## Example message

The engine prints the part below, then the fix above and a link to this page.
