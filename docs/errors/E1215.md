# E1215: Invalid material option

## What happened

A material factory received a value that one of its options does not take, such as an alpha mode that the engine does not know.

## How to fix it

Give alphaMode 'opaque' or 'mask'. three.js's alphaTest is alphaMode: 'mask' with alphaCutoff.

## Example

```text
E1215: materials.standard() got the alpha mode "cutout"; it takes 'opaque' or 'mask'.
```
