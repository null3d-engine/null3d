# E1223: Invalid feature description

## What happened

A call that registers a feature, a feature draw, a full-screen effect, a sky layer or a compute pass got a description it cannot take. The message names the value and the rule that it breaks.

<details>
<summary>Technical details: every description that the engine refuses</summary>

- Names: a name that is empty, longer than 64 characters, or holds a line break. A feature, output or debug view name that another feature has. An output name that names one of the engine's own resources.
- Frame points, kinds and order: a frame point or kind that does not exist, or two that do not go together. A kind, read, write or view without a frame point. An order outside its band.
- Resources, slots, views and outputs: an unknown resource, lighting slot or view, or the same one twice. An output without a neutral default. A lighting slot that another feature provides. A debug view that names an engine view, or whose set is not a function.
- Settings and budgets: an option that a description does not take. A setting whose presets are not four values from its range. A governor without a budget. A budget whose presets are not four times above 0, or whose minimum is outside 0 to 1.
- The GPU scope: a pass that `render.addPass()` did not return.

</details>

## How to fix it

Give each feature and output a name of its own. Give a frame point and a kind that go together, and keep the order inside its band. Name resources, lighting slots and views from the lists, and give every output a neutral default. One feature provides each lighting slot, and a setting takes the values that its range allows.

<details>
<summary>Technical details: what each kind of feature accepts</summary>

| Kind | Frame point | Views | Rules |
| --- | --- | --- | --- |
| Draw | 'opaque', 'transparent' or 'resolve' | main | The alpha mode must match the frame. |
| Full-screen effect | 'resolve' | main | Reads 'sceneColor', and 'sceneDepth' when its WGSL reads the depth. Writes 'sceneColor' alone. |
| Sky layer | 'background' | main, scenePass and reflection | Provides 'sky'. |
| Compute pass | 'background', 'opaque', 'transparent', 'resolve' or 'post' | main | Reads no scene resource. Publishes one output texture, or fills an instance draw's buffers. |

A full-screen effect publishes no texture and provides no lighting slot. A compute pass that fills an instance draw publishes no output. A budget gives its time in ms at full quality on each preset: four numbers above 0.

</details>
