# E1107: Object created twice

## What happened

The engine core received a second create command for one object, so the TypeScript side and the core disagree about the scene.

## How to fix it

This is an engine bug. Report it with the code that created the object.

## Example

```text
E1107: the object in slot 7 was created twice.
```
