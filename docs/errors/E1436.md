# E1436: Pick lost with the GPU

## What happened

A pick waited for the GPU to copy its pixel back when the browser took the GPU away. The engine started a new device, but the frame that recorded the pick drew on the lost device, so its read never lands. The pick is rejected rather than repeated on the new device.

## How to fix it

Ask for the pick again: the engine started a new GPU device, which answers a new pick. A pick that waits when the device is lost is rejected rather than repeated, because the frame that recorded it drew on the lost device.

## Example

```text
E1436: pick() was waiting for its read when the GPU was lost.
```
