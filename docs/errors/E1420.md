# E1420: Engine stopped

## What happened

Sketch code called the engine after the engine stopped, from a timer, a promise or an event handler that outlived destroy(). The call did nothing.

## How to fix it

Remove the sketch's timers, event listeners and message handlers in its onDestroy callback, which runs when the engine stops.

## Example

```text
E1420: a call reached the engine after it stopped.
```
