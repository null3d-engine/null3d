# E1308: GPU path not in this build

## What happened

This page's build holds the shaders of one GPU path, and this device would draw with the other. The Vite plugin's shaders.gpuPaths option left the other path out, for a deployment whose browser always offers the shipped one, such as an Electron app whose Chromium draws with WebGPU.

## How to fix it

Add 'webgl2' to the Vite plugin's shaders.gpuPaths option and build the page again, for a deployment whose devices may lack WebGPU. A build that ships one GPU path must always offer it.

[Where problems appear](../guides/debugging.md#where-problems-appear) says where each kind of error reaches your code.

## Example message

The engine prints the part below, then the fix above and a link to this page.

```text
E1308: this build ships only the WebGPU shaders, and this device would draw with WebGL2. The Vite plugin's shaders.gpuPaths option left WebGL2 out.
```
