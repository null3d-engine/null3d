# E1302: GPU lost

## What happened

The browser took the GPU away while the engine drew, for example after a driver reset or a GPU crash. The engine stopped drawing.

## How to fix it

Listen with engine.onFailure. Destroy the engine, put a new canvas element in place of the old one, and start the engine again on it.

## Example

```text
E1302: the render worker lost its GPU: the GPU device was lost.
```
