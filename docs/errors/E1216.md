# E1216: Invalid uniform or texture

## What happened

A custom material's or effect's uniforms or textures did not match its WGSL. The options take the names of the fields of `struct Uniforms` and of the WGSL's texture declarations. Give each one a value or texture of the type that its declaration takes, and leave standard values such as `color` to `set()`.

## How to fix it

Use the names of the fields of `struct Uniforms` in the WGSL, and the names of its texture declarations. Give each value the type that its declaration takes. Rename a field that has the name of a standard value, such as `color`. Give `post.setEffectUniform()` an effect that `post.addEffect()` returned.

<details>
<summary>Technical details: the value that each WGSL type takes</summary>

| WGSL type | Give |
| --- | --- |
| `f32` | a number |
| `i32` | a whole number |
| `u32` | a whole number |
| `vec2f` | an array of 2 numbers |
| `vec3f` | an array of 3 numbers, or a color |
| `vec4f` | an array of 4 numbers |
| `texture_2d<f32>` | a texture of one layer |
| `texture_2d_array<f32>` | a texture of one or more layers, from `textures.fromData()` with a depth or a KTX2 file of layers |

</details>

E1216: materials.shader.set() got speeed, which is not a uniform of the material's WGSL.
