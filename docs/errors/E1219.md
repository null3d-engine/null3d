# E1219: Invalid label

## What happened

ui.trackLabel() or ui.untrackLabel() got an id that is not a string with at least one character. Or the sketch tracked more labels at once than createEngine's maxLabels option allows: 4,096 by default.

## How to fix it

Give each label an id of its own, such as 'hp-12', and pass the same id to engine.labels.bind on the page. Untrack labels that you no longer show with ui.untrackLabel. To track more labels at once, raise createEngine's maxLabels option.

## Example

```text
E1219: trackLabel() could not track "hp-4097": the engine already tracks 4096 labels.
```
