# E1506: Feature draw after the first frame

## What happened

A draw whose instance count the GPU writes was created after the engine recorded its first frame, on a device that draws its scene directly. The direct path counts every draw on the CPU and keeps no indirect draw, so the frame has nowhere to copy the count. The frame records no draw.

## How to fix it

Create the draw in the sketch's setup, and await addComputeInstances() there, before the first frame. A device that draws directly fixes that choice at its first frame, and cannot take a draw whose count the GPU writes after it. Destroy the draw to let the frames draw again.

[Where problems appear](../guides/debugging.md#where-problems-appear) says where each kind of error reaches your code.

## Example message

The engine prints the part below, then the fix above and a link to this page.

```text
E1506: the frame failed: a draw whose instance count the GPU writes arrived after the first frame, and this device draws directly.
```
