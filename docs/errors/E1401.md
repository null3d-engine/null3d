# E1401: Not a sketch module

## What happened

The module passed to createEngine as the sketch does not export a sketch as its default export.

## How to fix it

End the sketch module with export default defineSketch(...), and pass that module to createEngine.

## Example

```text
E1401: /sketch.ts must export default defineSketch(...).
```
