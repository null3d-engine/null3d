# E1401: Not a game module

## What happened

The module passed to createEngine as the game does not export a game as its default export.

## How to fix it

End the game module with export default defineGame(...), and pass that module to createEngine.

## Example

```text
E1401: /game.ts must export default defineGame(...).
```
