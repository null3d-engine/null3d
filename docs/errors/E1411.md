# E1411: Asset not downloaded

## What happened

A loading call could not download its file. The server answered with an error, such as 404 for a missing file, or the network failed.

## How to fix it

Check the file's address: a relative address resolves against the page's address, and new URL('./file.png', import.meta.url) resolves against the sketch module's. Check that the server sends the file, and handle the error where the file is optional.

[Where problems appear](../guides/debugging.md#where-problems-appear) says where each kind of error reaches your code.

## Example message

The engine prints the part below, then the fix above and a link to this page.

```text
E1411: assets.loadTexture() could not download https://example.com/tex/brick.png: HTTP 404.
```
