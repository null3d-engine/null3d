# E1301: No usable GPU path

## What happened

The browser offers neither WebGPU nor WebGL2 for the way the engine was asked to draw.

## How to fix it

Remove a ?gpu= switch or createEngine gpu option that forces a path this browser lacks. Update the browser, or turn on hardware acceleration in its settings.

## Example

```text
E1301: no usable GPU path for ?gpu=webgpu in this browser.
```
