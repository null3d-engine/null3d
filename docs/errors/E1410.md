# E1410: Sketch module not loaded

## What happened

The sketch module that createEngine got did not load. It did not download, or its code threw an error while the module loaded.

## How to fix it

Pass the sketch as new URL('./sketch.ts', import.meta.url), so that the bundler ships the module and the engine finds it. When the download worked, the module's own code threw the error that the message quotes while the module loaded: fix that error.

## Example

```text
E1410: the sketch module https://example.com/assets/sketch-3f9c1a2b.js did not load: Failed to fetch dynamically imported module: https://example.com/assets/sketch-3f9c1a2b.js.
```
