# E1214: Invalid sketch option

## What happened

defineSketch() received an option out of its range. fixedRate must be a number above 0, and maxFixedSteps a whole number of 1 or more. The engine checks the options before it runs the setup function.

## How to fix it

Give fixedRate the fixed steps per second, a number above 0 such as 60 or 120. Give maxFixedSteps a whole number of 1 or more, such as 8.

## Example

```text
E1214: defineSketch() got 0 for fixedRate.
```
