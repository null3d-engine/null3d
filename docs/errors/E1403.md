# E1403: Engine core not ready

This page is generated from the engine's error table, `packages/engine/src/errors/codes.ts`. To change it, edit the table.

## What happened

An engine call ran before the engine core started in this worker, or the core started twice.

## How to fix it

Create objects in the setup function you pass to defineGame, or later, never when the game module loads.

## Example

```text
E1403: createMesh() ran before the engine core started.
```
