# E1403: Engine core not ready

## What happened

An engine call ran before the engine core started in this worker, or the core started twice.

## How to fix it

Create objects in the setup function you pass to defineSketch, or later, never when the sketch module loads.

## Example

```text
E1403: createMesh() ran before the engine core started.
```
