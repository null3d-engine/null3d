## What "settled" means here

A settled page draws the fully grown scene. Each load holds its own state. Creek Medium's two loads
hold 8,654 and 17,000 objects. Its settled triangles run 4.57 to 9.2 million.
The settle is a wall-clock wait while the page draws about one frame a second.
A load that draws fewer frames holds less. The counts are stated per load for that reason.

The ordinary page's row is a different measure. It reads 60.10 ms at Medium five seconds after the
first frame. That scene is still being built. The two are not one page measured twice. The settled
row is the scene a player holds, and the early row is not to be set against a ceiling.

figures over the BrowserStack tunnel. Hard rule 43's ten seconds governs the development machine's
own start at localhost, so the two measure different things and are not set against each other.

The late-start rule excludes it. The run file names it as the reading a later person should test.
